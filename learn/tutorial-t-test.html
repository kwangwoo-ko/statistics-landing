Your first t-test, start to finish

Follow along with built-in sample data: run a Welch's t-test and learn to read every number the tool reports.

Advertisement
Updated November 2026 · Beginner-friendly · Uses built-in sample data

This walkthrough uses the sample dataset that ships with the tool — two treatment groups plus a control, 20 values each, stored in a spreadsheet-style file. No download needed: the data loads with one click.

Step 1 — Open the tool and load the sample

Open GraphZen. In the "Upload Your Data" card, click "Try the sample data". You will see three columns appear: Control, Treatment_A and Treatment_B, 20 values each.

Step 2 — Select two groups

In "Select Numeric Columns to Compare", keep Treatment_A and Control checked and uncheck Treatment_B. We are comparing exactly two independent groups, which is what a t-test needs.

Step 3 — Choose the graph

Set Graph Type to Box Plot. A box plot shows each group's median and spread — a quick sanity check before testing. You will notice Treatment_A's box sits visibly higher than Control's.

Step 4 — Pick the test

In "Statistical Test", choose Welch's t-test. It compares the two group means without assuming equal variances — the safe default for real-world data. (Student's t-test is the alternative when spreads are similar.)

Step 5 — Generate and read the results

Press Generate Visualization. On the sample data you should see, approximately:

OutputExpected valueWhat it means
t statistic≈ 7.17How many standard errors apart the two means are.
Degrees of freedom≈ 34.7A Welch-specific quantity — it can be fractional.
p-value< 0.0001The difference would be extremely unlikely if there were no real effect.
Group tableA: M ≈ 26.8, SD ≈ 1.36
Control: M ≈ 24.1, SD ≈ 0.99		The effect itself — about 2.7 units higher on average.

The interpretation box below the table translates all of this into a sentence: the difference is statistically significant, and Treatment_A's mean is higher. If you switch the error-bar setting on a bar graph, the summary table follows your choice (SD, SEM or 95% CI). See SD vs SEM vs 95% CI if that choice is unfamiliar.

Reading the p-value correctly: p < 0.0001 does not mean "99.99% certain". It means data this far apart would be very rare if the groups were truly identical. The full story — including what p-values do not say — is in What is a p-value, really?

Step 6 — Export your figure

Under the graph, use Download PNG (high-resolution raster) or Download SVG (vector, scales perfectly in Word/LaTeX). Select "Show individual data points" first if you want the raw values visible — with 20 values per group, reviewers will appreciate it.

Common hiccups

  • Only one group is selected. The Generate button stays disabled until at least two columns are checked.
  • Your own file does not appear correctly. Make sure the first row contains column headers and values are numeric — the tool detects numeric columns automatically.
  • The wrong test was applied. With three or more groups selected, t-tests automatically become ANOVA. The results card tells you when this happens.

Next steps

  • Try the same comparison with the test picker — it will walk you through the choice for your own data.
  • Add Treatment_B back and switch to ANOVA — see Reading an ANOVA result for a guided version.
  • If your data is skewed, switch to Mann-Whitney U instead.
